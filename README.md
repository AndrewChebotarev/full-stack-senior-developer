## 0 🛠️ Инструменты (Git, Linux, Bash)
*Без этого ты не напишешь ни строчки кода в команде.*

- [ ] **Git:** От `init` до `reflog`. Внутреннее устройство (Blob, Tree, Commit). Git Flow / Trunk-Based.
- [ ] **Linux:** Структура FS, процессы, systemd, сети (`netstat`, `ss`).
- [ ] **Bash:** Скрипты, `grep`, `awk`, `sed`. Автоматизация деплоя.

---

## 1 🧠 Алгоритмы и структуры данных
*Сердце любого собеседования. Реализация на C++ и C#.*

- [ ] **Массивы и строки:** Бинарный поиск, два указателя, скользящее окно.
- [ ] **Связные списки:** Реализация, разворот, циклы (Флойд).
- [ ] **Стек/Очередь:** Реализация, Min Stack, очередь на двух стеках.
- [ ] **Хеш-таблицы:** Реализация с цепочками и открытой адресацией.
- [ ] **Деревья:** BST, AVL, обходы, поиск LCA.
- [ ] **Графы:** BFS, DFS, Дейкстра, Топологическая сортировка, Raft (упрощенно).
- [ ] **Динамическое программирование:** Рюкзак, LCS, редакционное расстояние.

---

## 2 ⚡ Память, железо и производительность
*Здесь проваливается 80% кандидатов на собеседовании.*

- [ ] **Стек, куча, статическая память:** Различия, выравнивание (padding).
- [ ] **Представление данных:** IEEE 754, Endianness.
- [ ] **Кэш и виртуальная память:** Кэш-линии, False Sharing, TLB, Page Fault.
- [ ] **Аллокаторы:** Пул памяти, Arena.
- [ ] **Многопоточность:** Мьютексы, спинлоки, Lock-free структуры (Treiber stack).
- [ ] **Профилирование:** `perf`, `dotnet-trace`, анализ дампов.

---

## 3 🚀 C++ (от 0 до эксперта)
*Мой основной язык.*

- [ ] **C++11/14:** Move-семантика, умные указатели, лямбды.
- [ ] **C++17/20:** `std::optional`, `std::variant`, Concepts, Coroutines.
- [ ] **Шаблоны:** SFINAE, CRTP, Variadic templates.
- [ ] **STL под капотом:** Как устроен `std::vector`, `std::string` (SSO).
- [ ] **Библиотеки:** Qt6 (GUI), Boost.Asio (сеть), GoogleTest (тесты).

---

## 4 🔷 C# / .NET (от 0 до CLR)
*Мой второй язык.*

- [ ] **Основы:** Value vs Reference, LINQ, делегаты.
- [ ] **Асинхронность:** `async`/`await`, State Machine, `IAsyncEnumerable`.
- [ ] **CLR:** GC (поколения, LOH), `IDisposable`, `WeakReference`.
- [ ] **ASP.NET Core:** Minimal API, Middleware, DI, gRPC.
- [ ] **Avalonia UI:** XAML, MVVM, стилизация.

---

## 5 🗄️ Базы данных (SQL → NoSQL)
*Без них ты не архитектор.*

- [ ] **SQL:** Сложные запросы, оконные функции, CTE.
- [ ] **Индексы:** B-Tree, покрывающие, частичные.
- [ ] **Оптимизация:** `EXPLAIN`, статистика, планы выполнения.
- [ ] **PostgreSQL Internals:** MVCC, WAL, изоляция, блокировки.
- [ ] **NoSQL:** MongoDB, Redis (кеширование, лидерборды).
- [ ] **Распределенные БД:** Шардирование, репликация, Vector DB (Milvus).

---

## 6 🌐 Сети и распределенные системы
*Вершина архитектуры.*

- [ ] **Основы сетей:** TCP/UDP, HTTP/2/3, WebSockets.
- [ ] **API:** REST, gRPC (Protocol Buffers).
- [ ] **Очереди:** RabbitMQ, Kafka (партиции, оффсеты).
- [ ] **Консенсус:** 2PC, Saga, Raft (реализация).
- [ ] **Согласованность:** CAP, PACELC, Vector Clocks.
- [ ] **Стриминг:** Kafka Streams, Flink.

---

## 7 ☸️ DevOps, K8s и инфраструктура
*Senior обязан уметь поднять свой сервис.*

- [ ] **Docker:** Multi-stage, healthcheck, Compose.
- [ ] **Kubernetes:** Pod, Deployment, Service, Ingress, Helm.
- [ ] **K8s (продвинутый):** StatefulSet, Operators, Istio.
- [ ] **CI/CD:** GitLab CI / GitHub Actions, ArgoCD (GitOps).
- [ ] **Observability:** Prometheus, Grafana, OpenTelemetry, Jaeger.

---

## 8 🎨 Фронтенд (React + TypeScript)
*Чтобы быть Fullstack-инженером.*

- [ ] **HTML/CSS:** Flexbox, Grid, медиазапросы.
- [ ] **JavaScript:** ES6, замыкания, Event Loop, промисы.
- [ ] **TypeScript:** Types, Generics, Utility Types.
- [ ] **React:** Хуки, Context, React Router, Redux Toolkit.
- [ ] **React Query:** Кеширование, оптимистичные обновления.
- [ ] **Next.js:** SSR, SSG, ISR, App Router.

---

## 9 🤖 AI и нейросети (инженерный уровень)
*Будущее, которое уже наступило.*

- [ ] **Математика:** Линейная алгебра, производные, вероятность.
- [ ] **Классический ML:** Линейная регрессия, Random Forest, метрики.
- [ ] **Deep Learning:** MLP, CNN, RNN, LSTM.
- [ ] **Transformer:** Self-Attention, BERT, GPT.
- [ ] **LLM:** Prompt Engineering, Fine-tuning (LoRA).
- [ ] **RAG:** LangChain, Vector Databases (Pinecone/Milvus).
- [ ] **MLOps:** ONNX, Triton, MLflow.

---

## 10 👑 Техническое лидерство
*Как превратиться из Senior в Staff.*

- [ ] **Code Review:** Модель SBI, как давать фидбек.
- [ ] **Процессы:** Scrum, Kanban, оценка задач.
- [ ] **Найм:** Как проводить собеседования, составлять тестовые.
- [ ] **Стратегия:** NFR (SLA/SLO), Roadmap, ADR, RFC.
- [ ] **Управление:** 1-on-1, мотивация, Blameless Post-Mortems.

---

## 11 🐹 Go (супер-перспективный язык)
*Язык облачной инфраструктуры.*

- [ ] **Основы:** Структуры, интерфейсы, ошибки.
- [ ] **Concurrency:** Goroutines, Channels, `select`, `sync`.
- [ ] **HTTP и gRPC:** REST API, middleware, gRPC-сервисы.
- [ ] **Базы данных:** `database/sql`, GORM, Redis, Kafka.
- [ ] **Инструменты:** `go mod`, `go test`, `pprof`.
- [ ] **Интерналы:** Планировщик (GMP), GC, устройство `chan` и `slice`.
